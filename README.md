## Вопросы по регламенту

В рабочей редакции пункта 2.3 предложено разрешить отображение номера редакции на титуле и в колонтитулах, сохранив коммит Git как однозначный идентификатор конфигурации. Изменение должно быть принято в установленном порядке.

Регламент предусматривает GitLab, задачи трекера и включение системных требований в раздел 2 СПТ. Сейчас используется локальная ветка репозитория с origin на GitHub, номер задачи не предоставлен, системные требования пока хранятся отдельным документом. Эти организационные расхождения требуют решения команды; они не объявлены устранёнными.

Исходный PDF хранится как полученный материал в `docs/input/`, а не как новый результат инспекции. Для размещения официального результата нужны реальная дата, проверяемый коммит, участники и решение; формат — DOCX по пункту 4.3 регламента.
